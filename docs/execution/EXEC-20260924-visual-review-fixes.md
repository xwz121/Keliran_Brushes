## 实施

| 问题 | 做法                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1    | 两类标签的每个 `span` 加白色实底 `#FFFFFF`、内边距 4px 8px，文字仍为深蓝 `#171D32`（约 16.7:1）。主视觉标签两端之间加 12px 间距，卡片标签限宽，避免长语言溢出。保留在图上而非移出，因为白块已足够且不改变版式                                                                                                                                                                                          |
| 2    | `.text-link.inverse` 颜色 `#E0B645`（对 `#171D32` 约 8.7:1），悬停改为白色（原通用悬停色为深蓝，在深蓝底上会消失），焦点轮廓同色。页脚“Request a quote”原已为该金色，现在也获得白色悬停                                                                                                                                                                                                                |
| 3    | ≤800px：`.hero-assurance` 为 `flex-direction: column`、间距 8px；`.capability-rail > .container` 为单列、`align-items: flex-start`、间距 10px；删除原 `span:first-child { width: 100% }` 与 ≤671px 的 12px 间距覆盖                                                                                                                                                                                    |
| 4    | 摘要来自 CMS `summary` 字段；种子脚本以指南第一节正文作为摘要，`rfq-checklist` 第一节是 Markdown 列表，本地库八种语言均如此（其他集合与指南没有）。新增 `plainSummary()`：仅当存在行首列表符号时，去掉 `- `/`* `/`• `，相邻列表项以 `·` 连接，其他行以空格连接；用于 `ResourceCard`、指南详情导语及 `pageMetadata` 的 description（同时作用于 Open Graph/Twitter）。CMS 原文、种子与发布内容包均未改动 |
| 5    | 查明 `materials` 是全语言共用的 Payload `select` 值，并兼作材料页链接键与筛选值；`registrationJurisdiction`、`addressCountry` 为未本地化文本字段。因此不能靠 CMS 按语言编辑解决，已写明需要人决定的术语、实现方式与法务取舍。之后 `296f755`（另一会话）已在代码中本地化注册地区与国家名，审查文档已相应标注；材料名仍待处理                                                                            |
